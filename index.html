جميع تفاصيل كورس تعليم الكوردية { السورانية } 💫

  1. تعليم اللغة الكوردية ( السورانية ).
  2. يبدأ من الصفر إلى أن تتعلم، والمدة غير محددة ✨
  3. أربعة - خمسة أيام في الأسبوع + محاضرات مباشرة ومحفوظة ومسجلة ✨
  4. يكون على ثلاث مستويات:
    ¹ ( قراءة - كتابة - مفردات - جمل بسيطة )
    ² ( ترتيب الكلام بصيغة صحيحة )
    ³ ( محادثات وحوارات ) ✨
  5. سعر الكورس فقط 200 ألف د.ع (إذا كان لديك صديق أو اثنان من طرفك فهناك خصم لك) ✨
  6. إضافة إلى فعاليات أخرى: (ترجمة أغاني • وصف صورة • قراءة القصص وترجمتها) ✨
